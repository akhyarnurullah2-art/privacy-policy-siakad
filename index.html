Kebijakan Privasi

Terakhir Diperbarui: 18 November 2026

Aplikasi Siakad SMPN 1 Kalinyamatan ("Aplikasi") dibangun oleh SMPN 1 Kalinyamatan untuk memfasilitasi kebutuhan administrasi dan absensi guru secara internal.

1. Data yang Kami Kumpulkan

Aplikasi ini meminta izin akses terhadap fitur perangkat keras berikut:

  • Kamera: Digunakan secara eksklusif untuk fitur Absensi Selfie dan pemindaian QR Code saat jadwal mengajar. Foto yang diambil akan dikirim dan disimpan dengan aman di server sekolah kami.
  • Lokasi (GPS): Digunakan untuk memvalidasi dan mencatat posisi geografis guru saat melakukan absensi kehadiran di lingkungan sekolah.

2. Penggunaan Data

Segala data yang dikumpulkan (termasuk foto selfie dan data lokasi) hanya digunakan untuk keperluan internal absensi, validasi kehadiran, dan administrasi sekolah. Kami tidak membagikan, menjual, atau menyewakan data pribadi kepada pihak ketiga mana pun untuk tujuan komersial.

3. Keamanan Data

Kami berusaha menggunakan standar keamanan yang wajar untuk melindungi data Anda. Kredensial login Anda disimpan menggunakan teknologi enkripsi (AES) pada perangkat Anda.

4. Penyimpanan Offline

Data absensi yang belum terkirim (saat offline) akan disimpan secara lokal di perangkat Anda dan akan secara otomatis diunggah (sync) ke server sekolah ketika perangkat kembali terhubung dengan internet.
